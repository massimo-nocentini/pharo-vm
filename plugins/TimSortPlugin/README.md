# TimSortPlugin

Sorting for Pharo 12 to 15 with timsort, the stable and adaptive sort of CPython, from [timsort.c](https://github.com/massimo-nocentini/timsort.c) fd70381: the plugin (`src/common`, the engine `src/engine`, the resumable sort `src/coro`, `include/`), which sorts Arrays of numbers or of strings, numeric buffers and permutations by keys in place, and runs the sorts by a sortBlock that name it (`TimSort sort:with:backend: #plugin`) on a C stack of their own, suspended at each comparison that the image answers (by default the image sorts by a sortBlock with its Smalltalk port, which was faster in every case measured); the library `libTimSortFFI` for VMs without it (`src/ffi`); and the explicit API of the class `TimSort` and of the `timSort` selectors (the submodule `timsort.st`), which leaves Pharo's own sort as it is; see [docs/TimSort.md](../../docs/TimSort.md) for the build options, the API, the semantics, the primitive and library contracts, the tests (`tests/`) and the benchmark (`bench/`).
The Smalltalk code is the git submodule `timsort.st` ([massimo-nocentini/timsort.st](https://github.com/massimo-nocentini/timsort.st); `git submodule update --init plugins/TimSortPlugin/timsort.st`), Tonel packages that Metacello loads with `BaselineOfTimSort`: `TimSort`, the facade, with `TimSort-Smalltalk`, a port of timsort.c to Smalltalk that answers the same results without the plugin (and the sorts by a sortBlock by default, on every VM), `TimSort-FFI`, which calls the library, and their tests `TimSort-Tests`, `TimSort-Smalltalk-Tests` and `TimSort-FFI-Tests`. `tests/load-timsort.st` loads them from the command line.
timsort.c has no licence file of its own: it is a port of the listsort of CPython (`Objects/listobject.c`), under the Python Software Foundation License Version 2, whose notice, with the changes made, is `LICENSE.timsort`, installed next to the plugin; the package `TimSort` is under the MIT licence of `timsort.st`, and its port `TimSort-Smalltalk`, a translation of timsort.c, also under that agreement (`timsort.st/LICENSE.timsort`).
