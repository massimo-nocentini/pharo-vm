# SimdUTFPlugin

Transcoding between UTF-8, UTF-16LE, UTF-16BE, Latin-1 and UTF-32, validation, and base64 for Pharo 12 to 15 with simdutf 9.4.0: the plugin (`src/common`, `src/cxx`, `include/`), the library `libSimdUTFFFI` for VMs without it (`src/ffi`), and the explicit API of the class `SimdUTF` (the submodule `simdutf.st`), which leaves Zinc as it is; see [docs/SimdUTF.md](../../docs/SimdUTF.md) for the build options, the API, the differences from Zinc, the primitive and library contracts, the tests (`tests/`) and the benchmark (`bench/`).
The Smalltalk code is the git submodule `simdutf.st` ([massimo-nocentini/simdutf.st](https://github.com/massimo-nocentini/simdutf.st); `git submodule update --init plugins/SimdUTFPlugin/simdutf.st`), Tonel packages that Metacello loads with `BaselineOfSimdUTF`: `SimdUTF`, which needs nothing but Zinc and answers the same results in pure Smalltalk without the plugin, `SimdUTF-FFI`, which calls the library, and their tests `SimdUTF-Tests` and `SimdUTF-FFI-Tests`. `tests/load-simdutf.st` loads them from the command line.
