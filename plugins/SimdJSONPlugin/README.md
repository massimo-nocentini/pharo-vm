# SimdJSONPlugin

JSON reading and writing for Pharo 15 with simdjson 5.0.5: the plugin (`src/`, `include/`), its reader `SimdJSONReader` and its writer `SimdJSONWriter`, with the API of NeoJSON (the submodule `simdjson.st`); see [docs/SimdJSON.md](../../docs/SimdJSON.md) for the build options, the API, the differences from NeoJSON, the tests and the benchmark (`bench/`).
The Smalltalk code is the git submodule `simdjson.st` ([massimo-nocentini/simdjson.st](https://github.com/massimo-nocentini/simdjson.st); `git submodule update --init plugins/SimdJSONPlugin/simdjson.st`), Tonel packages that Metacello loads with `BaselineOfSimdJSON`: `SimdJSON`, which needs no NeoJSON, `SimdJSON-Tests`, and `SimdJSON-NeoTests`, which compares the reader with NeoJSON. `tests/load-simdjson.st` loads them from the command line.
