    Settings
    
    
    
    
    
    
    Iceberg's https:// clones and fetches go to this CORS proxy: each request goes to the proxy's URL followed by the host and the path of the repository, such as github.com/pharo-project/pharo.git. The proxy sees the code and any credentials that pass through it, so give only one that you run or trust. When it is empty, the requests go to the repository itself, which works only for a server that lets this page in (CORS). This browser keeps it; a link cannot set it.
