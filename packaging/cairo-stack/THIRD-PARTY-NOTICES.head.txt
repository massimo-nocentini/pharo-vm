Source code (LGPL)
------------------

cairo is a separate shared library, which the VM does not link: the image
loads it by name, so it can be replaced with another build of cairo of the
same interface.
@IF glib@
The same holds for GLib @GLIB_VERSION@ (libglib, libgobject, libgio and
libgmodule), under the GNU Lesser General Public License version 2.1 or (at
your option) any later version.
@ENDIF@
@IF glib darwin@
On macOS libglib contains proxy-libintl 0.5 (GNU Library General Public
License version 2 or later), linked statically: libglib, itself under the
LGPL, is replaceable as a whole.
@ENDIF@
@IF pango@
The same holds for Pango @PANGO_VERSION@ (libpango and libpangocairo, and
libpangoft2 except on macOS; GNU Library General Public License version 2 or
later) and FriBidi (LGPL version 2.1 or later).
@ENDIF@
@IF pango mingw@
On Windows MSYS2's Pango also needs libpangowin32 (the same licence), and
libthai and libdatrie (LGPL version 2.1 or later), separate DLLs too;
libthai's word-break dictionary is not bundled.
@ENDIF@
The complete corresponding source code of cairo and of every
other library listed above is that of the pinned archive or package that
CAIRO-STACK.txt names, which its SHA256 identifies, built as
scripts/cairo-stack/ and cmake/cairoStack.cmake of the VM's repository say.
Every GitHub release of the VM attaches it as cairo-stack-sources.tar (the
pinned archives, cmake/cairo-stack/ and scripts/cairo-stack/).@SOURCES@
They are also available on request from whoever distributed this build.
