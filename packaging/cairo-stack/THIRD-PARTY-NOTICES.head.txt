Source code (LGPL-2.1)
----------------------

cairo is a separate shared library, which the VM does not link: the image
loads it by name, so it can be replaced with another build of cairo of the
same interface.  The complete corresponding source code of cairo and of every
other library listed above is that of the pinned archive or package that
CAIRO-STACK.txt names, which its SHA256 identifies, built as
scripts/cairo-stack/ and cmake/cairoStack.cmake of the VM's repository say.
Every GitHub release of the VM attaches it as cairo-stack-sources.tar (the
pinned archives, cmake/cairo-stack/ and scripts/cairo-stack/).@SOURCES@
They are also available on request from whoever distributed this build.
