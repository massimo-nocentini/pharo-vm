# The cairo stack of the native VMs: what scripts/cairo-stack/build.sh builds
# (Linux, macOS) and what scripts/cairo-stack/fetch-msys2.sh unpacks (Windows).
# docs/CairoStack.md explains the stack, the bump procedure and the security
# bumps.  This file is the single source: build.sh and fetch-msys2.sh (sh),
# cmake/cairoStack.cmake (file(STRINGS)), check.sh, check-pins.sh and
# check-latest.sh read it, and CI reads the cairo version from it.
#
# Lines ('#' starts a comment line; fields are separated by blanks):
#
#   <name> <version> <sha256> <file> <url> <platforms> <licence files...>
#       A source archive, built in the file's order.  <platforms> is "all" or
#       a comma list of linux, darwin.  The licence files are paths inside the
#       archive's top directory; the bundle's LICENSE.<name> concatenates them.
#       The comment line before it says how the archive was authenticated:
#       "# signed-by <primary key fingerprint> <signature url> ..." (the key is
#       keys/<name>.asc) or "# unsigned: <how the hash was cross-checked>".
#   mirror <name> <url>
#       A second URL of <name>'s archive (the fork's GitHub release asset).
#   native-ahead <name> <until YYYY-MM-DD> <reason...>
#       <name> may differ from its wasm pin (cmake/emscripten/deps/) until
#       that date: check-pins.sh warns, and fails after the date.
#   accepted-behind <name> <version> <until YYYY-MM-DD> <reason...>
#       The pin of <name> stays behind upstream's <version> on purpose until that
#       date: check-latest.sh (the weekly watch) reports it "accepted" instead of
#       BEHIND, and BEHIND again for any other newer release or after the date,
#       so every exception is reviewed (decision U4, docs/CairoStack.md).
#   msys2 <env> <kind> <package> <version> <sha256> <url> <source sha256> <source url>
#       Windows (decision U2): a binary package of MSYS2's <env> (ucrt64 for
#       x86_64, clangarm64 for ARM64) and its source package.  <kind> is root
#       (cairo, freetype), lib, or runtime (the C/C++ runtime of the toolchain,
#       which the VM's install step bundles from the compiler it was built
#       with).  Written by "fetch-msys2.sh --closure --env <env> --sources <dir>".
#   msys2-dll <env> <dll> <package>
#       A DLL of the closure of libcairo-2.dll and libfreetype-6.dll: what the
#       Windows bundle holds, and the import allow-list of check.sh.
#   msys2-mirror <base url>
#       A second location of every msys2 file: <base url>/<file name>.
#
# Every archive, package and source package is checked against its SHA256
# before anything is extracted.  Signatures are checked when bumping (gpgv with
# keys/*.asc), not by the build.
