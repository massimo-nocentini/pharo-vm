# The functions of SDL2 in the FFI registry of the Emscripten VM, the
# library SDL2 (the SDL2 class of OSWindow-SDL2, libSDL2-2.0.so.0, of
# cmake/emscripten/ffiLibraries.cmake), with WASM_SDL2.
# cmake/emscripten/ffiRegistry.cmake describes the format: a name per line,
# '#' starting a comment, and the '# unavailable' sections, whose names are
# left out.  Every other name must be declared by the headers of
# ffiLibraries.cmake, or the build stops.
#
# What Pharo 12 (build 1599) and Pharo 15 (build 41) bind to it, test
# packages included, as packaging/emscripten/tools/ffi-symbols.st lists them
# (the library SDL2 in its output), with the host VM:
#
#     pharo --headless <image> --no-default-preferences st ffi-symbols.st
#
# Both images bind the same 119, in OSWindow-SDL2 (the SDL2 class and the
# SDL_Window, SDL_Renderer, SDL_Texture... handles), audio, joysticks, game
# controllers and OpenGL included, which this SDL has but answers errors for
# (no device, no GL context).  The Windows API that OSWindow-SDL2 also binds
# (SDLWindowsPlatform: User32, Kernel32, Wtsapi32) is not SDL's, and is in
# no library of the registry.
#
