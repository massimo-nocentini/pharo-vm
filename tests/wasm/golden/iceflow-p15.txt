# iceflow-p15.txt - what tests/wasm/st/iceflow.st prints on the stock image
# of Pharo 15, with the libgit2 of the WebAssembly VMs
# (cmake/emscripten/deps/libgit2.cmake: libgit2 1.4.4, with WASM_LIBGIT2)
#
# Lane 66 (tests/wasm/lanes/66-libgit2.sh) runs iceflow.st in the node VM on
# the stock image and on the image of the world, and each line below must
# be a line of what it prints, which must have no other 'ffi method' line;
# '#' lines and blank lines are comments, and a value '<id>' stands for the
# short id of a commit, 7 hexadecimal digits, which changes with the time.
# These lines are the reference: a native Pharo VM (HOST_PHARO, 10.3.9 or
# later) is compared with them only as an advice.  None was: the Linux host
# VM 10.3.1 stops Pharo 15 at its check of the UUIDs.
#
# 'ffi method' lines are the methods of LGit whose callouts the flow
# compiled, 65 of them, those of Pharo 12 but for the options of a clone and
# of a fetch, which Pharo 15 takes from LGitCloneOptions and
# LGitFetchOptionsV160, and Pharo 12 from LGitCloneOptionsV140 and
# LGitFetchOptionsV140; 'callback classes' the classes of the 9 kinds of
# callbacks that it made for libgit2.  When Iceberg, LGit or the image
# change on purpose, run iceflow.st as lane 66 does, look at what changed,
# and update these lines.
